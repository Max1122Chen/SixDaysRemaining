## 1. 食物：具名物品「罐头」

- 食物应定义为**具体物品**，首选认知门槛低的 **「罐头」**。
- 获得食物时表述为「罐头 +1」等，而非抽象数值增量（战斗/出征环节）。
- **程序员侧约定（Max）：** 庇护所**分配**仍用 `GameState.foodStock` 整型维护；「罐头」语义主要在**出征战斗获得**环节体现，二者不冲突。

## 2. 卡牌战斗（`feat/combat` 参考）

### 2.1 防御（格挡）

- 防御 = **单纯格挡值**。
- **本次出牌结算完成后**，格挡值清零（不跨出牌保留）。

### 2.2 牌库 / 手牌流转

| 规则 | 说明 |
|------|------|
| 开局 | 基础卡组一次性洗牌，抽取**初始手牌** |
| 消耗牌 | 结算完成后放回**牌库底部** |
| 未打出牌 | 本回合留存于手牌的牌**全部保留**，不移动 |
| 每回合抽牌 | 回合开始时从牌库**顶部顺序**抽牌，自动补至手牌上限；已达上限不再抽 |

### 2.3 伤害与数值

- 「下毒」「易伤」等状态乘积因子**后续**再定；数值需等对应卡牌设计完成后反推攻击伤害。
- 支持**一位小数**；**结算时向下取整**（舍弃小数尾数，不四舍五入）。

### 2.4 效果触发时序（首版三档）

1. **玩家回合开始时**
2. **卡牌执行时**（打出瞬间）
3. **敌人死亡时**

其它时序（如回合结束）可作为扩展，但不在首版必做清单内。

## 3. 战斗入口与怪物（`feat/combat` 参考）

### 3.1 入口流程

- 玩家在庇护所点击 **「大门」UI** → 进入选择界面。
- **每日仅一场战斗**，对抗**单只怪物**。

### 3.2 路线选择（可裁剪）

| 方案 | 说明 |
|------|------|
| **理想** | 大门后提供**两条路线**，对应不同风格怪物 |
| **赶工** | 取消路线选择，文案插一句「你遇到了 XXX，开始战斗」 |

### 3.3 战斗结束

- 任意一方 **HP 归零** 即结束战斗环节。

### 3.4 怪物模板

- 规划 **4 套**怪物模板，其中 **2 套**含「问号」类特殊敌人（细节待 combat feat 设计）。

### 3.5 原型测试

- 设计师认可 **BattleOnly / 独立战斗原型** 方向，便于验证卡组与数值；具体描述待 combat 设计文档展开。
